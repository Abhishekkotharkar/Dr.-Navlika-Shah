# Dr. Navlika Shah's Healthy Smiles Dental Clinic

Static website for Dr. Navlika Shah's Healthy Smiles Dental Clinic in Vakola, Santacruz East, Mumbai.

## Files

- `index.html` - page content, SEO metadata and structured data
- `styles.css` - responsive design and visual styling
- `script.js` - mobile navigation behavior

Open `index.html` in a browser to view the site.
